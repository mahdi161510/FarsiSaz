# واژه‌نامه‌ی فارسی‌سازی Mafia III

این واژه‌نامه مرجعِ یکدست‌سازی اصطلاحات است. هر مترجمی که روی این پروژه کار
می‌کند **باید** همین معادل‌ها را به کار ببرد تا متن بازی یکدست بماند.

## ۱. قواعد کلی

| موضوع | قاعده |
|---|---|
| لحن منوها/تنظیمات/آموزش | فارسی معیار و رسمیِ روان (نه کتابی خشک) |
| لحن دیالوگ‌ها | محاوره‌ی تهرانی امروزی؛ لهجه‌ی جنوبی/سیاه‌پوستی انگلیسی با محاوره‌ی خودمانی و گاهی کوچه‌بازاری بازگردانده می‌شود |
| نیم‌فاصله | همیشه «به‌روزرسانی»، «کسب‌وکار»، «خانه‌ی امن» (U+200C) |
| نشانه‌های نگارشی | «.» «،» «؟» «!» فارسی؛ نقل‌قول با «» |
| اعداد در متن | فارسی (۱۲۳) **فقط** در متن‌های توصیفی؛ در رشته‌های قالب‌دار (`%s`) دست نزنید |
| اسامی خاص | آوانگاری فارسی (Lincoln Clay → لینکلن کلی) |
| توکن‌های فنی | `#E_CTRL_MAP#`, `%s`, `{0}`, `[RET]`, `&lt;bold&gt;`, `$` **عیناً** حفظ شوند |
| swear words | **ملایم‌شده**: «لعنتی»، «بی‌شعور»، «عجب گندی»، «اهریمن» - فحش رکیک جنسی/مذهبی سنگین نوشته نمی‌شود |
| توهین‌های نژادی دوران ۱۹۶۸ | **ملایم‌شده**: با «سیاه‌پوست»، «رنگین‌پوست» یا اشاره‌ی غیرمستقیم برگردانده می‌شود؛ واژه‌های تحقیرآمیز تاریخی به کار نمی‌روند |
| متن حقوقی و تیتراژ | ترجمه می‌شود + درج اعتبار «ترجمه‌شده توسط UnrealGame.ir» کنار نام سازندگان |
